## English

Repository scope: standalone solution files, no published package or shared test runner. Run each solution in its target language/problem harness; do not infer that all archived solutions pass from repository size or README examples.

A personal collection of algorithm solutions in Python, Rust, Go and SQL. Filenames start with the LeetCode problem number. Solutions are learning references rather than a packaged library.

## Tiếng Việt

Phạm vi repo: các file lời giải độc lập, không có package phát hành hoặc test runner dùng chung. Chạy từng lời giải bằng ngôn ngữ/harness của bài; số file hay ví dụ README không chứng minh mọi lời giải đã qua test.

Bộ sưu tập cá nhân các lời giải thuật toán bằng Python, Rust, Go và SQL. Tên file bắt đầu bằng số bài LeetCode. Đây là tài liệu học tập, không phải thư viện đóng gói.
